# Week 16 Task 4 — AI Model Optimization

This project evaluates practical optimization techniques for improving an AI model's deployment efficiency.

## Techniques
- Structural pruning: fewer Random Forest trees and bounded tree depth.
- Model compression: compressed joblib artifact.
- Benchmarking: accuracy, latency, and model size comparison.

## Run
```bash
pip install -r requirements.txt
python app/train_models.py
python app/benchmark.py
```
