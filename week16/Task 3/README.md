# Week 16 Task 3 — AI Model Monitoring & Evaluation

This project implements a simple production-style monitoring system for a deployed AI model.

## Deliverables
- Monitoring dashboard for accuracy, latency, and resource utilization
- Analysis report identifying performance issues and possible model drift
- Recommendations for improving model performance and stability
- Tests for the monitoring logic

## Run
```bash
pip install -r requirements.txt
python app/monitoring.py
streamlit run dashboard/monitoring_dashboard.py
```
