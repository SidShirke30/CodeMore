# Week 16 Task 1 — Cloud-Based AI Model Deployment Strategies

## Objective
Research and compare practical cloud-based deployment strategies for machine learning and AI models, focusing on containerization, serverless functions, and managed ML services.

## Deliverables
- `docs/deployment_strategies.md` — detailed research report
- `comparison/deployment_comparison.csv` — comparison matrix
- `comparison/deployment_comparison.md` — readable comparison matrix
- `presentation/week16_task1_deployment_strategies.pptx` — presentation summarizing findings

## Key evaluation criteria
- Scalability
- Cost model
- Maintenance and operational effort
- Control and flexibility
- Portability
- Cold-start / latency considerations
- Vendor lock-in
- Suitable workloads

## Recommended decision process
1. Define traffic pattern and latency requirements.
2. Estimate model size and compute requirements.
3. Identify data residency/security constraints.
4. Compare expected usage against pricing models.
5. Choose the simplest deployment model that meets reliability and performance targets.
6. Add monitoring, versioning, rollback, and security controls.
