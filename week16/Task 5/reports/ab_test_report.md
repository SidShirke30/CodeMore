# A/B Test Report

The example experiment compares model versions A and B using accuracy and latency.

## Findings
- Version B has higher observed accuracy in the sample.
- Version B also has lower average latency.
- The script performs a two-proportion z-test to determine whether the accuracy difference is statistically significant.
- The final recommendation is generated by the decision rule in `app/ab_test.py`.

## Production recommendations
- Define minimum sample sizes before making a rollout decision.
- Monitor confidence intervals and latency percentiles (P50/P95/P99).
- Segment results by important traffic cohorts.
- Stop or roll back the treatment if error rate or latency exceeds safety thresholds.
