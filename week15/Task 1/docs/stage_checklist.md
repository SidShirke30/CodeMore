# Deployment Stage Checklist

- [ ] Validate training data
- [ ] Train candidate model
- [ ] Evaluate candidate model
- [ ] Version source code and model
- [ ] Run automated tests
- [ ] Build Docker image
- [ ] Deploy approved image
- [ ] Run health checks
- [ ] Enable logging
- [ ] Enable performance and drift monitoring
- [ ] Define rollback procedure
- [ ] Define retraining trigger
