# Week 9 Task 5 — Final Capstone Project Proposal

## Proposed Capstone: Fair and Explainable Customer Churn Prediction Platform

This capstone proposes an end-to-end machine learning system that predicts customer churn, explains individual predictions, evaluates model performance, checks fairness across customer groups, and exposes the final model through a lightweight API.

The project intentionally combines concepts developed throughout the internship: data preprocessing, feature engineering, classical ML, ensemble learning, hyperparameter optimization, evaluation, explainability, fairness, and model deployment.

## Deliverable

The primary deliverable is a detailed capstone proposal. The project implementation will be developed after the proposal is approved.

See `docs/capstone_proposal.md` for the complete proposal.
